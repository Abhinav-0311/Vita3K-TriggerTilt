# Windows release build

## Provenance

The initial release preserves the executable manually tested on Windows in
Uncharted: Golden Abyss (PCSA00029). Its base is Vita3K+ `v1.1`, commit
`89496b8a7248768a876f34ad218c4b6e371588ec`. The `trigger-tilt-v1.1` branch
contains its corresponding source. The separate `trigger-tilt` contribution
branch ports the same motion patch to the current Vita3K+ `master`; it is not
the base of this release executable.

Toolchain: Visual Studio 2022 / MSVC 14.44, Release x64, CMake 4.4.3,
Qt 6.12.0 MSVC 2022 64-bit. Discord Rich Presence was disabled. Controller,
rendering, and camera implementation changes from Vita3K+ v1.1 are retained.
A small `util/fork_build.h` supplies the build label required by that tag's
logger; it does not alter emulation.

The executable was built before documentation-only commits. SHA-256:

```text
E63456C37B878FEB2ED13C5863A13EB9B898205874EBD75C4C7E97FAC055C8D9
```

The release is unsigned and community-built. Windows may show a reputation
warning. Verify the published checksum; do not disable antivirus protections.

## Build

```powershell
git clone --recurse-submodules --branch trigger-tilt-v1.1 https://github.com/Abhinav-0311/Vita3K-TriggerTilt.git
cd Vita3K-TriggerTilt
cmake --preset windows-vs2022 -DCMAKE_PREFIX_PATH=C:/Qt/6.12.0/msvc2022_64 -DUSE_DISCORD_RICH_PRESENCE=OFF
cmake --build build/windows-vs2022 --config Release --target Vita3K trigger_tilt_test
ctest --test-dir build/windows-vs2022 -C Release -R '^trigger_tilt$' --output-on-failure
```

Adjust the Qt path for your installation. The original build used an
unmodified curl 8.8.0 source checkout via
`-DFETCHCONTENT_SOURCE_DIR_CURL=<path-to-curl-8.8.0>`. Build scripts download
other dependencies as described in the repository. See `building.md` for
the normal toolchain requirements. A fresh-machine build of these instructions
has not been tested; the local build and SDL check passed.

## Source and licenses

The project retains its GPL-2.0-or-later notices and `COPYING.txt`. For this
binary distribution, GPL version 3 is used consistently with the Qt runtime's
LGPL-3.0 terms; no upstream copyright notice is removed. The binary archive
includes GPL/LGPL texts and dependency notices. The release also provides
source snapshots, dependency sources, and build recipes; do not rely on
GitHub's automatic source archive alone, which omits submodules.

The dynamically linked Qt libraries may be replaced or modified subject to
their own licenses; there is no anti-tamper restriction in this fork. No Qt
SDK installation is necessary to run the packaged build.

Dependency provenance includes:

- Git submodules at the exact revisions recorded by the release commit,
  including SDL, Dynarmic, Boost, and the FFmpeg build recipes.
- Static FFmpeg: Vita3K/ffmpeg-core `02f4f2691b0efffff8923235baf146a87fc37263`,
  vcpkg `34823ada10080ddca99b60e85f80f55e18a44eea`, FFmpeg 7.1.2 and the
  patches/recipes in that pinned vcpkg port plus `ffmpeg.patch`.
- curl 8.8.0 source (unmodified; native Windows TLS).
- Qt 6.12.0: qtbase, qtmultimedia, qtsvg, and qtimageformats. Qt multimedia's
  bundled FFmpeg DLLs report version 9.0.1; their corresponding release source
  is provided separately from the emulator's static FFmpeg 7.1.2.
- OpenSSL 3.6.1 DLLs from the FireDaemon package selected by the existing
  build scripts; the upstream source and Apache license are included.

The release manifest records archive checksums. Runtime files are copied from
the tested build's output through an allowlist, not from a gameplay directory.
User configuration, logs, shaders generated by games, firmware, games, and
saves are excluded. The built-in shaders are emulator resources, not game
caches.
